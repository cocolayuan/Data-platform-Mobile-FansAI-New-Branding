# Data platform-Mobile-FansAI New Branding

FansAI 数据中台的移动端交互演示。打开后默认进入增长页，使用底部导航切换增长、客户、决策和工作台。手机可直接操作，桌面浏览器以手机宽度展示。

**[打开在线 Demo](https://cocolayuan.github.io/Data-platform-Mobile-FansAI-New-Branding/)** · **[下载完整单文件 HTML（ZIP）](https://github.com/cocolayuan/Data-platform-Mobile-FansAI-New-Branding/releases/download/v1.0.0/FansAI-Mobile-Final.zip)**

## 四个 Tab

| 页面 | 可以看什么 | 可以试什么 |
| --- | --- | --- |
| **[增长 · Growth](https://cocolayuan.github.io/Data-platform-Mobile-FansAI-New-Branding/?tab=growth)** | 把 ROI、经营利润和渠道投放放在一起，看收入来自哪里、花费落在哪里。 | 切换今天、近 7 天或本月，查看 ROI 曲线，再打开渠道投放明细。 |
| **[客户 · Customer](https://cocolayuan.github.io/Data-platform-Mobile-FansAI-New-Branding/?tab=customer)** | 从签约金额、收款进度一路看到线索转化、BD 业绩与客户集中度，也可查客户资料和项目。 | 在经营看板点「项目视角」切换到「💰 已开票」，对照已回款和应收账款。 |
| **[决策 · Decisions](https://cocolayuan.github.io/Data-platform-Mobile-FansAI-New-Branding/?tab=decisions)** | 待审批、抄送我的、已审批和我提交的事项集中在一处。 | 在待办决策中切换卡片和列表，按客户、申请人或项目搜索，体验模拟审批。 |
| **[工作台 · Workbench](https://cocolayuan.github.io/Data-platform-Mobile-FansAI-New-Branding/?tab=workbench)** | 汇集客户业务、产品增长和内部项目的常用入口。 | 打开创作者名录搜索或筛选创作者，再从财务分析查看结算概览和季度开票、回款。 |

## 离线打开

下载上方 ZIP，解压后用 Chrome 打开 `FansAI-最新版.html`。数据、字体、图像和微动画随文件提供，无需安装依赖或配置 API Key。

演示使用随版本保存的数据快照。筛选、搜索与审批交互在浏览器中运行，审批操作只作用于本次演示会话。
